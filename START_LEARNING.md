## Your learning loop

Use this sequence for every mission:

1. **Read the mission** — open **Command Center → Begin Investigation**, or **Learning Map → Receiving Dock**.
2. **Understand the deliverable** — read the brief, expected deliverable, concepts, and mission checklist.
3. **Download the working data** — use **Download Working Data** in Mission Workspace.
4. **Do the work outside the website** — use Excel, SQL, or notes as instructed. Save the artifact in a local portfolio folder.
5. **Check your work** — record five evidence-based observations or corrections.
6. **Write the evidence reflection** — explain the main finding, why it matters, and the recommended action. Minimum 20 characters; a useful reflection is normally 3–6 sentences.
7. **Set an honest self-check score** — do not award yourself a high score without evidence.
8. **Submit evidence** — verified work updates XP and unlocks the next mission.
9. **Review supporting areas** — use Simulation Room, Analytics Lab, Competency Matrix, Portfolio Vault, Rewards Center, and Manager's Office.

## Day 1 — Map the inventory flow

Estimated time: **50–60 minutes**

### Outcome

Create an inventory-flow worksheet and five operational observations that trace one SKU through:

`Supplier → Purchase Order → Receiving → Storage → Sale/Issue → Return/Adjustment`

### Steps

1. Open **Learning Map**.
2. Click the active **Receiving Dock** node. It opens Mission 1 directly.
3. Read **Map the inventory flow** and its expected deliverable.
4. Click **Download Working Data**.
5. Create a workbook named `day-01-inventory-flow.xlsx`.
6. Add a sheet named `Inventory Flow` with these columns:
   - Step
   - Source document or transaction
   - Quantity increase/decrease
   - Inventory field affected
   - Control or validation
   - Potential failure
7. Add rows for purchase order, receipt, put-away/storage, customer issue/sale, transfer, return, and adjustment.
8. Write five observations. Examples of categories—not answers to copy:
   - Timing mismatch
   - Unit-of-measure mismatch
   - Missing receipt
   - Duplicate transaction
   - Unapproved adjustment
9. Save the workbook in a portfolio folder such as:

   ```text
   Inventory-Analyst-Portfolio/Week-01/Day-01/
   ```

10. Return to Mission Workspace.
11. Set the self-check score based on your actual work.
12. Write a reflection using this structure:

    ```text
    Finding:
    Evidence:
    Business impact:
    Recommended action:
    ```

13. Click **Submit Evidence**.
14. Confirm that Mission 2 becomes available and XP appears on the header/dashboard.

## What each screen does

| Screen | Use it for |
|---|---|
| Command Center | See the next available mission, XP, KPIs, and exceptions |
| Learning Map | Open the active learning node and understand future progression |
| Mission Workspace | Read instructions, download data, record reflection, and submit evidence |
| Simulation Room | Change demand, variability, lead time, service level, and review-period assumptions |
| Analytics Lab | Open actionable Excel, SQL, and dashboard practice workspaces |
| Competency Matrix | See skill gaps; it is a read-only readiness view, not a button grid |
| Portfolio Vault | Open/close the case-file evidence checklist |
| Rewards Center | Activate rewards after requirements are met |
| Manager's Office | Practice operational decisions and read immediate feedback |

## Evidence standard

A mission is not complete merely because the website was opened. Keep the actual artifact:

- Excel workbook, SQL script, dashboard, analysis notes, or management memo
- Five observations or corrections
- A concise evidence reflection
- A defensible self-check score

Do not use unsupported numbers or claims in portfolio material. Everything should be explainable in an interview.

## If something looks locked

Locked learning nodes and missions are intentionally disabled. Complete the currently available mission first. Analytics Lab can preview related future work, but locked mission submission remains unavailable until prerequisites are complete.
